# Design Guidelines Project Goal

Build a codebase-agnostic design-guidelines skill based on shared design principles, organized for reuse across any UI project, installable via terminal from https://github.com/Wiltermoodj/design, and maintainable as an Open Knowledge Format publication with durable link and metadata guarantees.
